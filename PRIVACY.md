# Privacy

TAYA-STEPS performs calculations in the browser. Saved scenarios and imported parameter sets are stored locally on the user's device.

The application does not collect participant or patient data, does not use analytics or advertising trackers, does not require tracking cookies and includes no client-side API secrets.

External AI briefings are generated locally. Nothing is automatically transmitted. If the user chooses an external provider, the application copies the reviewed briefing to the clipboard and opens the provider homepage. The user decides whether to submit it.

Users should not place personal, patient or confidential information in scenario names, imported files or external briefings.
