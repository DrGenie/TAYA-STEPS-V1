# Accessibility

TAYA-STEPS targets WCAG 2.2 AA for the research prototype interface.

The streamlined interface includes skip links, visible keyboard focus, semantic headings and forms, 44px minimum controls, responsive layouts down to 320px, screen-reader status updates, accessible data-table alternatives for charts, reduced-motion support, keyboard-operable disclosure controls, arrow-key navigation for result tabs, and focus trapping with focus return for modal dialogs and the Policy Assistant drawer.

Automated axe checks and Playwright viewport tests are included in the repository. The CI workflow runs these checks after dependencies are installed.

No project contact email has been invented. Accessibility feedback should be directed to the TAYA research team through the contact channel supplied with the research project.
